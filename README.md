# Data Science Project: What Factors Influence Restaurant Tips?

## Research Question
Do total bill amount, day of week, and smoking status meaningfully influence tip size?

## Dataset
- Source: Seaborn built-in `tips` dataset (public demo dataset)
- License: Open access, no redistribution restrictions; intended for educational use only.

## Methods & Tools
- Python 3.11, pandas, seaborn, matplotlib
- Exploratory data analysis (summary statistics, grouped bar charts, scatter plots)

## Key Findings
Weekend diners (Saturday/Sunday) tend to leave higher average bills. 
Smokers show more variance in tip amount relative to bill size, though no strong causal claim can be drawn from observational data.

## Limitation
The dataset is small (244 rows) and collected from a single restaurant context, limiting generalizability.
